🔐 Sicherheitskonfiguration

Beim ersten Start wird ein persönlicher Sicherheitscode eingerichtet.

Der Code muss mindestens 8 Zeichen lang sein. Eine praktische Maximallänge gibt es nicht.

Wichtig:

Der Sicherheitscode wird nicht gespeichert. Wenn er vergessen wird, können die verschlüsselten Daten nicht wiederhergestellt werden.

🔐 Datenschutz / V11

Die Personendaten werden automatisch verschlüsselt gespeichert.

Die Verschlüsselung verwendet AES-256-GCM in Verbindung mit einem persönlichen Sicherheitscode und einem gerätegebundenen Schlüssel.

Der Sicherheitscode wird nicht gespeichert. Bei Inaktivität wird die Anwendung automatisch gesperrt.

Die E-Mail-Funktion verwendet weiterhin mailto:. Beim Erstellen einer E-Mail werden die Daten als Klartext an die installierte Mail-App übergeben.
