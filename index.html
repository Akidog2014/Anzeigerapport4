🔐 Automatische Verschlüsselung aktiv
🔐 Datenschutz V8

Die erfassten Personendaten werden automatisch verschlüsselt auf diesem Gerät gespeichert.

Die Verschlüsselung verwendet AES-256-GCM über die Web Crypto API.

Der Verschlüsselungsschlüssel wird als nicht exportierbarer CryptoKey im lokalen IndexedDB-Speicher verwaltet.

Die E-Mail-Funktion ist davon ausgenommen: Bei Verwendung von mailto: werden die Daten an die installierte Mail-App übergeben.

Hinweis:

Beim Erstellen der E-Mail werden die eingegebenen Personendaten an die Mail-App übergeben.
