🔐 Datenschutz / V11.1

Die eingegebenen Personendaten werden automatisch verschlüsselt gespeichert.

Die lokale Speicherung verwendet AES-256-GCM mit einem gerätespezifischen Schlüssel und einem von Ihnen eingegebenen Code/Passwort.

Der Code selbst wird nicht gespeichert. Ohne den richtigen Code können die gespeicherten Daten nicht entschlüsselt werden.
